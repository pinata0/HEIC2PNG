# 2. HEIC 디코딩 라이브러리 붙이기

- 처음에는 `heic2any` 같은 브라우저용 라이브러리를 사용한다.
- 현재 프로젝트에는 `package.json`이 없으므로 1차 구현은 CDN 방식으로 연결한다.

## 2-1. 라이브러리 연결

- `index.html`에 `heic2any` CDN 스크립트를 추가한다.
- `app.js`보다 먼저 로드되도록 순서를 확인한다.
- 페이지 로드 후 `heic2any` 전역 객체가 존재하는지 확인한다.

## 2-2. 변환 상태 정의

`app.js`에 다음 상태를 추가한다.

- `selectedFile`: 사용자가 선택한 원본 `File`
- `convertedBlob`: 변환된 PNG `Blob`
- `objectUrl`: 다운로드에 사용할 임시 URL
- `isConverting`: 중복 변환을 막기 위한 상태

새 파일을 선택하거나 파일을 삭제할 때 이전 `Blob`과 Object URL을 초기화한다.

## 2-3. 입력 파일 검증

파일을 변환하기 전에 다음 순서로 검사한다.

1. 파일이 존재하는지 확인한다.
2. 확장자가 `.heic` 또는 `.heif`인지 확인한다.
3. 파일 크기가 20MB 이하인지 확인한다.
4. 검증에 실패하면 변환 버튼을 비활성화하고 오류 메시지를 표시한다.

HEIC 파일은 브라우저에 따라 `file.type`이 비어 있을 수 있으므로 초기 버전에서는 확장자 검사를 기준으로 한다.

## 2-4. HEIC 변환 함수 작성

`heic2any`에는 `File`을 별도 변환 없이 `Blob`으로 전달한다.

```text
File
-> Blob(File 자체)
-> heic2any({ blob, toType: 'image/png' })
-> PNG Blob
```

라이브러리 입력에 문제가 생기는 경우에만 `file.arrayBuffer()`로 `ArrayBuffer`를 만든 뒤 `Blob`으로 감싸는 방식을 추가한다.

`heic2any`의 반환값이 `Blob` 또는 `Blob[]`일 수 있으므로, 변환 함수의 반환값은 항상 단일 PNG `Blob`이 되도록 정규화한다.

## 2-5. 변환 버튼에 비동기 흐름 연결

변환 버튼을 누르면 다음 순서로 처리한다.

1. 선택된 파일이 없거나 이미 변환 중이면 종료한다.
2. `isConverting`을 `true`로 바꾸고 버튼을 비활성화한다.
3. 상태 문구를 `변환 중...`으로 변경한다.
4. `heic2any`를 실행해 PNG `Blob`을 얻는다.
5. 변환된 `Blob`을 `convertedBlob`에 저장한다.
6. `URL.createObjectURL(convertedBlob)`로 임시 URL을 만든다.
7. 임시 URL을 다운로드 함수에 전달한다.
8. 성공 시 완료 메시지를 표시한다.
9. 실패 시 사용자용 오류 메시지를 표시하고 개발자 콘솔에는 원인을 기록한다.
10. `finally`에서 변환 상태와 버튼을 복구한다.

## 2-6. PNG 다운로드 구현

- 원본 파일명에서 `.heic` 또는 `.heif` 확장자를 제거한다.
- 같은 이름에 `.png`를 붙인다.
- 임시 `<a>` 요소의 `download` 속성으로 다운로드를 실행한다.

예시:

```text
photo.heic -> photo.png
image.HEIF -> image.png
```

## 2-7. Object URL 정리

Object URL은 메모리를 사용하므로 다음 시점에 `URL.revokeObjectURL()`로 해제한다.

- 새 파일을 선택할 때
- 파일 삭제 버튼을 누를 때
- 페이지를 떠날 때

다운로드 직후 즉시 해제하면 일부 브라우저에서 다운로드가 중단될 수 있으므로, 초기 구현에서는 새 파일 선택·초기화 시점에 정리한다.

## 2-8. 변환 중 UI 처리

변환 중에는 다음 동작을 막는다.

- 변환 버튼 연속 클릭
- 같은 파일의 중복 변환

상태 문구는 최소한 다음 네 가지를 구분한다.

- `파일을 선택하면 변환할 수 있어요.`
- `PNG로 변환하는 중이에요.`
- `PNG 변환이 완료됐어요.`
- `이 파일을 읽을 수 없어요. 다른 HEIC 파일을 선택해 주세요.`

## 2-9. 1차 구현 범위

처음에는 변환된 PNG를 자동 다운로드하는 것까지 구현한다. 변환 결과 미리보기와 재다운로드 버튼은 이후 단계에서 추가한다.

미리보기를 추가할 때의 흐름은 다음과 같다.

```text
PNG Blob
-> URL.createObjectURL()
-> img.src
-> 변환 결과 미리보기
```

## 2-10. 테스트 순서

### 정상 케이스

- `.heic` 파일
- `.heif` 파일
- 대문자 확장자
- 한글·공백이 포함된 파일명

### 오류 케이스

- HEIC가 아닌 파일
- 20MB 초과 파일
- 손상된 HEIC 파일
- 지원되지 않는 HEIC 인코딩
- 변환 버튼 연속 클릭

### 결과 확인

- PNG 파일이 실제로 다운로드되는지 확인한다.
- 다운로드 파일명이 `.png`로 바뀌는지 확인한다.
- 다운로드한 PNG가 정상적으로 열리는지 확인한다.
- 파일을 여러 번 바꿔도 Object URL이 누적되지 않는지 확인한다.

최종 흐름은 다음과 같다.

```text
File 선택
-> 확장자·크기 검증
-> File을 HEIC decoder에 전달
-> PNG Blob 반환
-> URL.createObjectURL()
-> PNG 다운로드
-> 새 파일 선택 시 Object URL 정리
```
