# pending
업로드 된 HEIC 파일
- 아직 변환 작업이 시작 되지 않은 상태
- 변환 대기열에 들어가 있는 파일임을 나타낸다

# converting
HEIC 파일
- HEIC 디코딩 및 PNG 변환을 수행 중인 상태
- 현재 Worker/WASM이 해당 파일을 처리하고 있음을 나타낸다.
- UI에서는 로딩이나 진행 중 표시를 할 수 있다.

# completed
변환 작업이 끝난 파일
- PNG 결과가 정상적으로 생성된 상태
- 생성된 PNG Blob이나 다운로드 URL을 사용자에게 제공할 수 있음을 나타낸다.

# Failed
변환을 시도한 HEIC 파일
- 디코딩 또는 PNG 생성 과정에서 오류가 발생한 상태
- 실패한 파일을 구분하고 오류 메시지 표시나 재시도 기능을 제공하기 위해 사용한다.

따라서 이 상태들은 다중 파일 변환 과정에서 
각 파일의 생명 주기를 관리하기 위한 상태 값이다.
