# HEIF
High Efficiency Image File Format

JPEG처럼 이미지를 저장하는 형식이지만, 
더해서 여러 이미지와 메타데이터를 함께 담을 수 있는 컨테이너 형식

담을 수 있는 종류
```
일반 이미지 한 장
여러 장의 이미지
연속 촬영 이미지
썸네일
EXIF 같은 메타데이터
알파 채널
깊이 정보(depth map)
HDR 관련 정보
```

## HEIC
HEVC(H.265) 코덱으로 압축된 이미지를 HEIF 컨테이너에 저장한 경우

## 왜 생겼을까?
JPEG보다 같은 화질에서 파일 크기를 줄이기 위해서
